# Web dev project
This was my submission for one of my university assignments. It was written in 1 month in pure JavaScript, HTML and CSS (as well as GLSL for shaders), and only uses 1 library which wasn't written by me. [The library in question is TWGL](https://twgljs.org/), and it is a library with a few small helper functions for working with WebGL directly. 


This project has been done in 2024 while I was learning WebGL, and despite the 1 month time limit I have been able to implement quite a few features:
- The 3D Engine has a fully functional skeletal animation system.
- The 3D Engine has support for GLTF files, albeit with a few limitations. It can load 3D models and their animations, but cannot load PBR materials or cameras.
- Both the hex editor and the 3D engine have basic scripting support (Loading files, playing animations, moving objects etc)
